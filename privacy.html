Privacy

Last updated: November 24, 2026

The Lumen Kids website is a static site. It has no accounts, no sign-up forms that send information, no analytics and no advertising.

What happens in your browser

All Creative Studio tools run entirely in your browser. Names, topics and word lists you type are used to draw the sheet on your own device. They are not sent to us or stored by us.

Services that load this site

  • GitHub Pages hosts the site. Like most web hosts, GitHub may record technical information such as IP addresses for security and operations. See the GitHub Privacy Statement.
  • Google Fonts provides the typefaces. Your browser requests the font files from Google’s servers. See the Google Fonts privacy FAQ.

Children

We don’t knowingly collect personal information from anyone, including children under 13, because the site has no way to receive it.

Changes and questions

If this ever changes, for example when the Lumen Kids app launches with accounts, we will update this page first. Questions are welcome on GitHub.
